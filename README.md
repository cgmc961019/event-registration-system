# EventPulse 活動通 — 活動／講座／工作坊雲端報名系統

本系統採用 **GitHub + Vercel + Supabase** 現代無伺服器架構建置，支援公開活動瀏覽、會員註冊登入、動態自訂報名表單、銀行匯款後五碼回報審核、電子票券 (QR Code) 與現場掃描報到核銷。

## 系統功能架構

1. **公開活動前台 (`探索活動`)**
   - 精選活動推薦、關鍵字即時搜尋、活動類別篩選（講座／工作坊／課程／論壇／社群聚會）。
   - 活動詳情頁：顯示時間地點、議程內容、講師介紹、各票種即時剩餘名額與進度條。
   - 動態報名表單：自動帶入會員聯絡資料，並依活動設定動態渲染自訂問題欄位（單行文字、多行問答、下拉單選、必填檢查）。

2. **學員／會員專區 (`我的票券與報名`)**
   - 會員註冊與登入（已整合 Supabase Auth 自動開通，註冊後立即登入）。
   - 查詢歷史報名狀態（待匯款回報、待審核對帳、報名成功、已現場報到、已取消）。
   - **付費報名匯款回報**：顯示主辦單位銀行帳號，線上填寫轉帳帳號後五碼與金額。
   - **電子票券 (QR Code)**：免費票或經後台確認收款後，一鍵出示專屬加密 `checkin_token` QR Code。

3. **主辦方管理後台 (`主辦方管理後台`)**
   - 總覽儀表板：統計總活動數、有效報名數、待對帳筆數、已確認收款總額與現場報到人數。
   - **活動上／下架與表單欄位管理**：新增或編輯活動、一鍵切換上架狀態（已上架／草稿／已截止）、管理多種票價名額、**動態新增或刪除自訂報名表單欄位**。
   - **報名名單與對帳審核**：檢視學員自訂欄位回答與匯款帳號後五碼，一鍵「確認收款核發票券」或匯出含 UTF-8 BOM 的 Excel (CSV) 名單。

4. **現場報到核銷台 (`現場 QR 報到台`)**
   - 支援開啟手機／平板／筆電相機鏡頭即時掃描學員 QR Code 自動簽到。
   - 支援輸入驗證碼 (`checkin_token`) 或於名單直接點擊手動簽到，並具備防重複報到提示。
